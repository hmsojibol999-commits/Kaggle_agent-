# WordClip Studio

ইংরেজি শব্দের ছোট ভিডিও (৯:১৬, TikTok/Shorts/Reels-এর মাপে) প্রায় নিজে নিজে বানানোর টুল।
প্রতিটি ভিডিওতে ৩টি শব্দ থাকে: ছবি, তীর, “What’s this called?” প্রশ্ন, কাউন্টডাউন, উত্তর, ধীরে উচ্চারণ আর বানান।
ভিডিওর ভেতরে শুধু ইংরেজি থাকে।

সব ভারী কাজ **GitHub Actions** করে। আপনার ফোন শুধু স্ক্রিন দেখায় আর ট্যাপ নেয়। কোনো সার্ভার চালু রাখতে হয় না, কোনো টাকা লাগে না।

## আপনাকে শুধু এই ৩টি কাজ করতে হবে

1. ওয়েব পাতা খুলে **Prepare** চাপুন।
2. প্রায় ১ মিনিট পরে ৩টি শব্দ আর প্রতিটির ৪টি ছবি আসবে। প্রতিটি শব্দের জন্য:
   - একটি ছবিতে ট্যাপ করে বাছুন।
   - তারপর ছবির জিনিসটির ওপর ট্যাপ করুন। তীর আর জুম ঠিক ওইখানে যাবে।
   - চাইলে আঙুল টেনে ছবির কাটাছাঁটা সরান।
   - ছবি পছন্দ না হলে **আরও ছবি**, শব্দটা পছন্দ না হলে **বাদ দিন** (তার জায়গায় অতিরিক্ত শব্দ আসবে), অথবা **নিজের ছবি** দিন।
3. **Build** চাপুন। ২–৫ মিনিট পরে **ভিডিও ডাউনলোড করুন** বোতাম আসবে (HD MP4)।

## শুরুর আগে যা লাগবে (সব বিনামূল্যে)

| জিনিস | কোথায় পাবেন |
|---|---|
| GitHub অ্যাকাউন্ট | github.com |
| Groq API key | console.groq.com (শব্দ বানানো ও ভয়েসের জন্য) |
| Pexels API key | pexels.com/api (ছবির জন্য) |

Key দুটি **কখনো চ্যাটে বা কোডে বসাবেন না।** শুধু GitHub-এর Secrets-এ বসবে (SETUP_BN.md-এ দেখানো আছে)।

## কোন ফাইল কী করে

| ফাইল/ফোল্ডার | কাজ |
|---|---|
| `docs/` | ফোনে খোলা ওয়েব পাতা (GitHub Pages থেকে চলে) |
| `engine/` | Python কোড: শব্দ বানানো, ছবি খোঁজা, ভয়েস, ভিডিও রেন্ডার, মান-পরীক্ষা |
| `.github/workflows/` | ৫টি কাজ: Prepare, More images, Build, Check setup, Voice test |
| `github-workflows/` | ওপরের লুকানো `.github/workflows`-এর হুবহু কপি। শুধু ফোন থেকে আপলোডের সুবিধার জন্য, repo-তে তোলার দরকার নেই |
| `config.yaml` | আপনার সেটিং: চ্যানেলের নাম, থিম, ভয়েস, শব্দ-সংখ্যা |
| `assets/fonts/` | ভিডিওর ফন্ট |
| `assets/music/` | চাইলে নিজের mp3 রাখার জায়গা (ঐচ্ছিক) |
| `tests/` | স্বয়ংক্রিয় পরীক্ষা (চালাতে না চাইলে আপলোড না করলেও চলবে) |

## ডকুমেন্টের তালিকা

- **SETUP_BN.md**: প্রথমবার চালু করার ধাপে ধাপে নির্দেশ। **এটা দিয়ে শুরু করুন।**
- **TROUBLESHOOTING_BN.md**: সবচেয়ে সম্ভাব্য ১৫টি সমস্যা ও সমাধান।
- **CONFIG_BN.md**: ভয়েস, থিম, চ্যানেলের নাম, শব্দ-সংখ্যা, মিউজিক বদলানোর উপায়।
- **ARCHITECTURE.md**: ডেভেলপারদের জন্য (ইংরেজিতে)।

## জেনে রাখা ভালো

- **ফ্রি সীমা বদলাতে পারে।** Groq, Pexels আর GitHub Actions-এর ফ্রি সীমা সময়ের সঙ্গে বদলায়। কয়েক সপ্তাহ পরপর একবার দেখে নিন।
- **Groq-এর ভয়েস (Orpheus) ফ্রি প্ল্যানে চলবে কি না নিশ্চিত নয়।** না চললে টুল নিজে নিজে edge-tts ভয়েসে চলে যায়, আর Release-এর নোটে লেখা থাকে কোন ভয়েস ব্যবহার হয়েছে।
- **edge-tts অনানুষ্ঠানিক সেবা।** যেকোনো সময় বন্ধ হতে পারে।
- **একসঙ্গে একটি কাজই চলে।** একটার মধ্যে আরেকটা শুরু করলে পরেরটা লাইনে থাকে। লাইনে দুটোর বেশি থাকলে পুরনোটা বাতিল হয়ে যায়। তাই বোতাম একবারই চাপুন।
- **ছবির কৃতজ্ঞতা:** সব ছবি [Pexels](https://www.pexels.com) থেকে। প্রতিটি ভিডিওর Release-এ `credits.json` আর নোটে ফটোগ্রাফারের নাম থাকে। ভিডিও পোস্টের বর্ণনায় “Photos: Pexels” লিখে দিলে ভালো।
- **নিজের ছবি** দিলে সেটার কপিরাইটের দায়িত্ব আপনার।
- ভিডিওতে কোনো TikTok ওয়াটারমার্ক নেই। নমুনা ভিডিওর ছবি, অডিও বা লোগো কিছুই ব্যবহার হয়নি।
